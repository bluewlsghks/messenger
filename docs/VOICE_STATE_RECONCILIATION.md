# 분산 통화 상태와 화면 대조

2026-10-07. `58ea66a` 검증 실행 `37588676313`에서 두 앱의 RabbitMQ 메시지 전달·Elasticsearch 투영/삭제·권한 철회 6개 검사는 통과했습니다. 두 앱 사이의 실제 WebRTC 연결·양방향 RTP·음소거·종료도 진행됐지만, 이어지는 새로고침 후 거절 검사에서 발신 화면이 남아 전체 실행은 실패했습니다.

분산 사용자 레지스트리는 새로고침 직후 이전 연결 정보를 잠시 유지할 수 있습니다. STOMP 전송 성공만으로 특정 탭이 종료 이벤트를 처리했다는 보장은 없습니다. 활성화된 등록 통화가 있을 때만 기존 인증 API `/api/voice/current`를 3초 간격으로 대조합니다. 서버에 통화가 없으면 해당 로컬 연결·마이크·타이머를 정리하고, 다른 탭이 수락했으면 이 탭만 정리합니다. 통화가 없거나 아직 발신 등록 중이거나 실시간 연결이 끊겼으면 주기 조회를 하지 않습니다.

한 번에 한 조회만 수행합니다. HTTP 오류를 종료로 오인하지 않으며, 응답 대기 중 통화·수명주기·수락 상태가 바뀌었으면 오래된 응답을 버립니다. 조회나 수신 대조가 마이크를 자동 요청하거나 다른 탭의 통화를 종료하지 않습니다. 조회는 현재 제어 상태의 복구이며 SDP/ICE 전체 재생 또는 브라우저별 영속 수신 ACK 기능은 아닙니다.
